## What I'm working on

- **Industrial quality analytics** at Autodidactic Technologies: full-stack R&D on a production platform that turns live sensor data into quality insight, covering real-time ingestion, time-series storage and TimescaleDB analytics, FastAPI services and Vue 3 dashboards. *325 commits and 115 merged pull requests in the last 12 months.*
- **LLM-guided reinforcement learning** (TÜBİTAK-funded R&D): LLM-generated reward functions for simulated agents (Qwen 2.5 via Ollama), domain fine-tuning of Llama 3 and Qwen 2.5 with Unsloth, and a dogfight sandbox simulation.
- **Miss Minutes**, a personal side project: a voice-first command center in Next.js with an LLM assistant that uses tools over my own data, Google OAuth integrations and listening analytics.
